## 시뮬레이션 개요

항만의 AGV·야드트랙터·전기트럭·충전시설·선박(AMP)을 수백 개의 자율 에이전트로 재현합니다.

- **에이전트 상태기계**: 자기 홈 블록(CY)에서 작업 → SOC 저하 → 통로 그리드 경유 충전소 이동 → 대기/충전 → 복귀
- **통로 라우팅**: 컨테이너 블록 사이 세로 통로 + 가로 레인 + 우측 충전 복도만 주행
- **전력 계산**: 충전 중 차량 kW + AMP 접속 선박 부하 → 실시간 전력 피크
- **시나리오 4종** (헤더에서 전환, 실제 시뮬에 반영)
  | 시나리오 | 전동화율 | 충전기 | 정책 |
  |---|---|---|---|
  | BASELINE | — | 8기 | — |
  | EV-80% | 80% | 8기 | — |
  | CHG-14 | 80% | 14기 | 증설 |
  | SMART+ESS | 80% | 14기 | 스마트충전 + ESS |

- **실시간 UI**: 스웜 메시(근접 에이전트 통신망), 충전 빔, 전력 부하 곡선, 대기열 추이, SOC 분포, 이벤트 로그, 충전소 노드 상태표
